# MijaTimeSync

Sync time from your phone with Mija LYWSD02 gadget

## Build

Requires Flutter 3.50 or newer. Android builds require the Android SDK and accepted SDK licenses; iOS builds require macOS and Xcode.

```sh
flutter pub get
flutter run
```

Create an Android release APK with `flutter build apk --release`.

## Android APK

[Download MijaTimeSync 1.0.0 for Android](releases/MijaTimeSync-1.0.0.apk)

This APK is built in release mode but signed with the debug key configured in this project. Configure a private release keystore before publishing through an app store.
